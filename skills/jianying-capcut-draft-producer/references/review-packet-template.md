# Review Packet Template

Use this structure before any media generation:

```markdown
**文案判断与推荐目标时长**
- 类型：
- 推荐目标时长：
- 判断：

**推荐制作方案**
- 文案：
- 时长：
- 画布：剪映 16:9 横屏
- 配音方向：
- 画面：
- 素材归档：
- 包装方向：
- 声音层：
- 交付：

**可调整制作单**
- 文案处理：原文配音 / 轻度口播化 / 压缩版 / 扩展版
- 时长策略：保留估算时长 / 压缩到推荐时长 / 指定目标时长
- 视频规格：剪映 16:9 横屏
- 配音策略：清晰女声 / 沉稳男声 / 调语速 / 调情绪 / 用户指定声音
- 配音预览：确认制作方案后先给可预览声音选项，再生成完整旁白
- 画面策略：素材 API 自动匹配 / 只用用户素材 / 混合模式 / 缺镜头留占位
- 素材归档：下载后用中文内容加情绪重命名 / 复制到新路径需再次确认
- 包装强度：克制 / 标准 / 强包装
- 包装预览：确认制作方案后先给可预览包装样式，再组装草稿
- 字幕与花字：基础字幕 / 重点词花字 / 标题金句和段落包装
- 声音层：旁白 / 背景音乐 / 音效强度与音乐情绪
- 草稿交付：草稿名 / 是否打开剪映 / 是否保留占位镜头清单

**等待确认**
请确认推荐方案，或逐项改动制作单。我收到确认后会先给你配音和包装预览选项，再进入最终生成。
```
